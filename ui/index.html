What “deterministic” means

OpenSearch always runs the registered tools in the same order. The LLM does not choose tools, indexes, or when to stop.

What it does not mean

Generated wording can still vary. Temperature 0 reduces variation; grounding and citations constrain the answer.

Run it from the CLI

  --question "What can you say about ML Commons?"

The browser and CLI call the same registered OpenSearch agent. The UI adds a side-by-side retrieval explanation; it does not replace the agent.

Building blocks

Where each capability lives

BM25

OpenSearch inverted index ranks exact lexical evidence.

Vector search

Local open-weight model embeds the query; Lucene HNSW retrieves neighbors.

Hybrid RRF

A search pipeline combines lexical and vector rank positions.

LLM generation

MLModelTool calls Claude Sonnet 5 through the secured Aiven AI Gateway connector.

Agent

ML Commons orchestrates VectorDBTool then MLModelTool and stores conversation memory.

Grounding

The prompt requires indexed evidence, source URLs, and an explicit refusal when unsupported.
